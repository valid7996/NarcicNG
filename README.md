## ✨ Features

- 🌐 **Auto-Updated Configs** — Free high-speed servers updated automatically
- ⚡️ **Real-Time Ping Test** — Choose the fastest server instantly
- 🔀 **Split Tunneling** — Select which apps use the VPN tunnel
- 🎨 **Clean Dark UI** — One-tap connection experience
- 🔒 **Multiple Protocols** — VLESS, VMess, Trojan, Shadowsocks, Hysteria2, WireGuard
- 📖 **100% Open Source** — Fully transparent codebase

## 📥 Download

Get the latest version from **[Releases](https://github.com/valid7996/NarcicNG/releases/latest)**:

| File | Description |
|------|-------------|
| `NarcicNG-arm64.apk` | Most modern phones ✅ Recommended |
| `NarcicNG-armeabi.apk` | Older phones |
| `NarcicNG-universal.apk` | All devices |

### Installation
1. Download the right APK file
2. Tap the file to install
3. If Play Protect warns → tap **Install anyway**
4. Open the app and tap **Connect**!
